An AI-powered video and audio intelligence tool designed to transcribe, translate, summarize, and query content from YouTube videos and local media files.
Built with a hybrid transcription architecture using OpenAI Whisper (for local English transcription) and Sarvam AI (for Hinglish / Indic speech-to-text and translation), backed by LangChain, Groq LLMs, and a ChromaDB RAG pipeline.
